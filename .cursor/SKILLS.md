# Skills del proyecto Feedback Widget

Skills instaladas en `.cursor/skills/` para este repositorio.

## Project-specific

| Skill | Cuándo usar |
|-------|-------------|
| `bun-typescript-widget` | Implementación, tests y validación del widget Bun/TS |

## CodeConductor / OpenSpec

| Skill | Cuándo usar |
|-------|-------------|
| `openspec` | Editar BACKLOG.md, `openspec validate`, plan BC-xxx |
| `cc-feature` | Flujo completo feature (task-coach → architect → implementer) |
| `cc-fix` | Bug fix con Task Card |
| `cc-review` | Revisión estructurada pre-merge |
| `cc-tdd-cycle` | Ciclo Red-Green-Refactor estricto |
| `cc-test-plan` | Plan de pruebas sin código |

## Calidad y seguridad

| Skill | Cuándo usar |

| `testing-tdd` | Pirámide de tests, naming, mocks |
| `security` | BC-010 API key, OWASP, validación input |
| `evaluation` | Scorecards y criterios de aceptación |
